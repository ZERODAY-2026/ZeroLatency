# Backend Architecture & Technical Specification

## Overview

The Private Legal Document Triage Agent is a local-first, privacy-preserving document analysis backend designed for Hacktoberfest 2026 (PS2). It ingests legal agreements (PDF and plain UTF-8 text), performs deterministic structural segmentation and regex fact extraction, indexes passages for BM25 retrieval, and queries a local Google Gemma 3n model running inside Ollama over loopback HTTP (`127.0.0.1:11434`) to extract candidate legal findings and answer specific user questions.

Every quotation generated by the language model undergoes strict programmatic verification against the source document text before being marked as verified.

## Component Details

### 1. Document Parsing (`src/document_parser.py`)
- **PDF Extraction**: Uses PyMuPDF (`fitz`), opened from an in-memory byte stream (`stream=target.read_bytes(), filetype="pdf"`). This ensures no native OS file locks linger on Windows filesystems, permitting immediate unlinking and cleanup.
- **Text Extraction**: Validates UTF-8 encoding; supports form-feed (`\f`) page delimiters or automated character-based pagination.
- **Guards**: Enforces `max_file_bytes` (50MB default), `max_pdf_pages` (300 pages default), and checks for encrypted/password-protected PDFs (`EncryptedDocument`).

### 2. Chunking & Indexing (`src/chunker.py`, `src/qa.py`)
- Chunks text at clause and paragraph boundaries up to `chunk_max_chars` (2400) with a 200-character overlap.
- Builds an in-memory BM25 index using Okapi BM25 ranking (`k1=1.5`, `b=0.75`) with token stemming and punctuation normalization.

### 3. Model Client & Model Selection (`src/gemma_client.py`, `src/models.py`)
- Connects strictly to the local Ollama instance over loopback (`127.0.0.1:11434`).
- **Supported Models**:
  - `gemma3n:e2b`: Gemma 3n E2B (Default, ~4.5B params, Q4_K_M, ~2.4GB VRAM footprint)
  - `gemma3n:e4b`: Gemma 3n E4B (~4B active params)
- **Manual Selection**: Model selection is explicit and manual via API parameters or settings. **Automatic model switching based on confidence is prohibited.**
- **Safe Residency**: Calls `POST /api/generate` with `keep_alive: "0s"` or prepares new models to unload prior models, ensuring only the user-requested model resides in memory.

### 4. Citation Validation (`src/citation_validator.py`)
- Programmatically verifies each quotation in model findings against the extracted page text.
- Standardizes quotes (normalizes whitespace, unicode quotes, case).
- Marks findings as:
  - `verified`: Exact or high-confidence fuzzy substring match found on the referenced page.
  - `unverified`: Quote does not exist on the specified page or fails character length thresholds (`min_quote_chars=20`).

### 5. Deterministic Facts & Checklist (`src/facts.py`, `src/checklist.py`)
- Key facts (parties, dates, currency amounts, jurisdictions) are extracted with audited regular expressions, not generative hallucination.
- Clause checklists match standard operational terms (termination, dispute resolution, governing law, confidentiality) deterministically.

## Interfaces: FastAPI & Direct Python

### FastAPI REST Contract (`src/api.py`)
Designed for web frontends (e.g. React/Vite):
- `GET /health`: Returns service status and legal disclaimer.
- `GET /models`: Lists supported and currently installed Ollama models.
- `POST /documents`: Uploads document (PDF/TXT) and creates workspace.
- `GET /documents`: Lists active documents.
- `GET /documents/{doc_id}`: Retrieves document metadata.
- `DELETE /documents/{doc_id}`: Securely deletes document files and indices.
- `POST /documents/{doc_id}/search`: Performs BM25 retrieval for a query.
- `GET /documents/{doc_id}/pages/{number}`: Returns text content of a page.
- `GET /documents/{doc_id}/pages/{number}/image?quote=...`: Returns page image with highlighted quotation.
- `POST /documents/{doc_id}/analyze`: Dispatches asynchronous triage job with optional `model` override.
- `GET /documents/{doc_id}/result`: Retrieves completed triage findings, facts, and checklist.
- `POST /documents/{doc_id}/ask`: Answers specific user questions with evidence passages.
- `GET /jobs/{job_id}`: Polls analysis progress and state.
- `POST /jobs/{job_id}/cancel`: Aborts running analysis.

### Direct Python / Streamlit API (`src/pipeline.py`, `src/service.py`)
```python
from src.pipeline import DocumentSession

session = DocumentSession("contract.pdf")
result = session.analyze(model="gemma3n:e2b", on_progress=lambda done, total: print(f"{done}/{total}"))
answer = session.ask("What is the governing law?", model="gemma3n:e2b")
```

## Error Handling

Standardized HTTP error code mappings:
| Exception | Status Code | Description |
|---|---|---|
| `UnsupportedFormat` | 415 | File format is not supported (.pdf, .txt only) |
| `UnreadableDocument` | 422 | Corrupted file or invalid UTF-8 encoding |
| `EncryptedDocument` | 422 | Password protected PDF |
| `NoExtractableText` | 422 | Empty or scanned PDF with no extractable text |
| `LimitExceeded` | 413 | Document size exceeds 50MB or too many documents open |
| `UnsupportedModel` | 400 | Model identifier is not on the supported allowlist |
| `EmptyQuestion` | 400 | Question string is empty or whitespace |
| `DocumentNotFound` | 404 | Document ID does not exist |
| `ModelMissing` | 409 | Selected model has not been pulled in Ollama |
| `Busy` / `AnalysisCancelled`| 409 | Analysis in progress or was cancelled |
| `PrivacyViolation` | 403 | External network or DNS request attempted |
| `OllamaUnavailable` | 503 | Local Ollama service is not running |
| `InsufficientMemory` | 507 | System or GPU out of memory |
| `ModelTimeout` | 504 | Inference exceeded timeout threshold |
| `InvalidModelOutput` | 502 | Model failed structured JSON validation |
