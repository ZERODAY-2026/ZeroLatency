What Redline Guarantees

  • check_circle Total memory isolation: Documents are converted into memory objects and never stored in cloud datastores or external servers.
  • check_circle Zero analytics or beacons: No Mixpanel, PostHog, Google Analytics, Sentry, or telemetry SDKs are packaged in this binary.
  • check_circle Ephemeral prompts: Context prompts are treated as transient memory buffers and zeroed out upon session reset.

Explicitly Out of Scope

  • cancel Statutory legal counsel: Redline extracts and organizes text. It does not certify contractual legality or judicial admissibility.
